PROJECT IDENTITY
==========================================================

This system is not intended to be:
- a chatbot,
- a wrapper around an API,
- a simple automation tool,
- or a static assistant.

This project is the construction of a:

MODULAR EVOLUTIONARY COGNITIVE OPERATING SYSTEM

A continuously adapting intelligence infrastructure capable of:
- autonomous learning,
- memory persistence,
- self-reflection,
- planning,
- tool usage,
- reasoning,
- evolution,
- specialization,
- and long-term cognitive growth.

The system is designed as a digital organism rather than traditional software.
