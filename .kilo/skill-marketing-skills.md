# Marketing Skills

## Campaign Management

```bash
marketing create-campaign --platform xhs --budget 1000
marketing analyze-performance --campaign-id CAMPAIGN_ID
marketing optimize --target roi=2.5
```

## SEO Tools

```bash
seo research "target keywords" --location global
seo analyze-url "https://example.com" --competitors 5
seo track-rankings --keywords-file keywords.txt
```

## Social Media Scheduling

```bash
social schedule --platform twitter --content "message" --time "2024-01-01T12:00"
social batch-schedule --file posts.json
social analytics --platform all --period last-30-days
```
