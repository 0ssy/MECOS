# To Issues

Break down plans/specifications into independently grabbable vertical-slice issues.

Process:
1. Analyze the plan/spec/PRD
2. Identify vertical slices (each slice = complete feature that works end-to-end)
3. Create issues with clear acceptance criteria
4. Each issue can be picked up and completed independently
