# Grill Me - Relentless Interview

Before implementing anything, run a grilling session to ensure alignment. When triggered:
- Ask detailed questions about the problem, users, edge cases, error states, non-goals
- Challenge assumptions and incomplete specifications
- Ensure concrete examples and clear success criteria

This prevents misalignment and ensures plans are complete before code begins.
