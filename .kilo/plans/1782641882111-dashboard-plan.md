# Real-Time Outreach Dashboard Plan

## Goal
Add a real-time browser dashboard to observe the outreach pipeline without touching running processes.

## Constraints & Preferences
- Brown/green Hermis terminal aesthetic, monospace, big title banner.
- Light background (not dark theme).
- Read-only: polls JSON files every 2 seconds, no writes.
- Launched alongside `main.py` as integrated FastAPI endpoint on localhost.

## Implementation Tasks

### 1. Add FastAPI dashboard endpoint to `main.py`
- Import `FastAPI` and `DashboardService` at top.
- After scheduler starts, create dashboard app on a separate port (e.g. 8080).
- Serve static HTML at `/` and JSON status at `/api/status`.
- Keep it read-only: no writes to outreach data.

### 2. Create `outreach/dashboard.py`
- `DashboardService` class with `get_status()` method.
- Read: `data/outreach/daily_metrics.jsonl` (last entry), `data/outreach/outbox/` (file count + recent 10), `data/outreach/skipped_leads.jsonl` (line count), `data/outreach/replies.json` (recent 10), `data/outreach/revenue_ledger.json` (total revenue).
- Return JSON with: `today_sent`, `today_drafts`, `today_flagged`, `today_rejected`, `today_skipped_icp`, `total_replies`, `total_revenue`, `scheduler_running`, `last_send_timestamp`, `recent_emails`, `recent_replies`.

### 3. Create `outreach/dashboard.html`
- Single static HTML file served by FastAPI.
- Hermis-style title banner: large monospace text, brown/green palette, light background.
- Grid of tiles for each metric.
- Tables for recent emails and replies.
- Auto-refresh via JavaScript `setInterval` polling `/api/status` every 2000ms.
- Use inline CSS/JS; no build tools required.

### 4. Data Mapping
- `daily_metrics.jsonl` → today's metrics (filter by `date` field, take last entry).
- `outbox/` → count today's files + last 10 by mtime.
- `skipped_leads.jsonl` → count lines (total filtered).
- `replies.json` → count + last 10 entries.
- `revenue_ledger.json` → sum `amount` field across all entries.

### 5. Validation
- Start `main.py`, open `http://localhost:8080`.
- Confirm tiles populate within first poll.
- Trigger a manual outreach cycle and confirm dashboard updates within 2 seconds.
- Confirm no errors in `main.py` logs related to dashboard.

## Out of Scope
- Authentication, multi-user access, remote hosting.
- WebSocket or push-based updates (polling is sufficient).
- Mobile-responsive design (desktop terminal aesthetic only).
